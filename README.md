## Featured Projects

### [Koku / 观子](https://github.com/yiyangbear/koku)

[![Java](https://img.shields.io/badge/Java-25-ED8B00?logo=openjdk&logoColor=white)](https://github.com/yiyangbear/koku)
[![JavaFX](https://img.shields.io/badge/UI-JavaFX-007396)](https://github.com/yiyangbear/koku)
[![AI](https://img.shields.io/badge/AI-Minimax%20%2B%20Alpha--Beta-8A2BE2)](https://github.com/yiyangbear/koku)

A cross-platform desktop collection of **Tic-Tac-Toe, Connect Four, Gomoku, and Six-in-a-Row**. It supports local multiplayer and three levels of AI opponents using random play, game-specific heuristics, Minimax, and Alpha-Beta pruning. The project also includes configurable rules, timers, undo, bilingual interfaces, light/dark themes, JUnit tests, and native packaging.

### [Used Car Price Prediction](https://github.com/yiyangbear/used-car-price-prediction)

[![Python](https://img.shields.io/badge/Python-ML%20Pipeline-3776AB?logo=python&logoColor=white)](https://github.com/yiyangbear/used-car-price-prediction)
[![Model](https://img.shields.io/badge/Model-Random%20Forest-2E8B57)](https://github.com/yiyangbear/used-car-price-prediction)
[![Notebook](https://img.shields.io/badge/Workflow-Jupyter-F37626?logo=jupyter&logoColor=white)](https://github.com/yiyangbear/used-car-price-prediction)

An end-to-end regression study on **4,009 used-car listings**, covering exploratory analysis, leakage-safe preprocessing, model comparison, target diagnostics, feature engineering, cross-validation, and holdout evaluation. The final workflow explains how engineered vehicle features and extreme-price listings affect MAE, RMSE, and R².

### [Random Melody Generator](https://github.com/yiyangbear/Melody-Generator)

[![Python](https://img.shields.io/badge/Python-PyQt5-3776AB?logo=python&logoColor=white)](https://github.com/yiyangbear/Melody-Generator)
[![MIDI](https://img.shields.io/badge/Output-MIDI-FF6B6B)](https://github.com/yiyangbear/Melody-Generator)
[![Music](https://img.shields.io/badge/Modes-11-6F42C1)](https://github.com/yiyangbear/Melody-Generator)

A PyQt5 desktop application that generates MIDI melodies across **11 musical scales and modes**. Users can configure key, mode, tempo, and length; the generator applies melodic-contour, interval, rhythm, and voice-leading rules before exporting a standard MIDI file.
